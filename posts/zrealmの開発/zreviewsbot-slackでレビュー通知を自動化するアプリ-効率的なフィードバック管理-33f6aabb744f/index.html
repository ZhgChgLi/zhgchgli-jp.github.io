ZhgChgLi / ZReviewsBot

ZReviewsBot

ZReviewsBot は無料のオープンソースプロジェクトで、AppチームがApp Store（iOS）とGoogle Play（Android）での最新レビューを自動で追跡し、指定したSlackチャンネルに通知を送ることで、リアルタイムにAppの状況を把握できるよう支援します。

  • ✅ より新しく信頼性の高いAPIエンドポイントを使ってiOSアプリのレビューを追跡 (技術詳細)

  • ✅ 両プラットフォームのレビュー追跡に対応（iOS & Android）

  • ✅ キーワード通知スキップ機能対応（広告スパム防止）

  • ✅ カスタマイズ設定が自由自在

  • ✅ GitHub Actionsを使ったスケジュール自動化ロボットのデプロイをサポート

[2022/07/20 更新]

App Store Connect API がカスタマーレビューの読み取りと管理をサポート しており、このボットは今後のアップデートで、Fastlane — Spaceship を使ってバックエンドからレビューを取得する方法に代わる実装を行います。

起源

前回の「AppStore APP’s Reviews Slack Bot 那些事」の研究を経て、新しいiOSのレビュー取得ツールを完成させました。同じ問題を抱える方々のために、サイドプロジェクトとしてオープンソースで公開するのが良いと思いました。

札幌駅 <-> 定山渓 往復バスチケット

申し訳ありませんが、このリンクは翻訳対象のMarkdown段落ではないため、翻訳できません。翻訳したいMarkdown形式の文章を提供してください。

新千歳空港から札幌駅へのJRは本数が多く、飛行機の到着時間が正確に読めなかったため、事前に切符は購入しませんでした。定山渓温泉へはバスのみ利用可能で、2025/12 最新交通情報によると、3つのルートがあります：

  1. [予約必須] [約60分] 札幌駅 → Kappa Linerバス乗車 → 定山渓温泉。
    時刻表はこちら

  2. [予約不要] [約70分] 札幌駅 → 真駒内駅 → バス → 定山渓温泉。

  3. [予約不要] [約120分] 新千歳空港 → 空港バス（北斗交通） → 真駒内駅 → 定山渓温泉。

ルート(1) — かっぱライナー号 / Kappa Liner は一番スムーズで便利です。時刻を調べたところ、飛行機到着後に入国し、JRで札幌駅まで行き、駅を出てから午後4時発（秋冬限定便）に十分間に合うので、事前にネットで予約しました（外国人も利用可能です！）。

往路 札幌駅 -> 定山渓：

https://www.jotetsu.co.jp/bus/kappa_liner/index.html

  • 赤字の便は秋冬季のみ運行しています。札幌駅16:00/17:00発の便は定山渓車庫前までの運行です。

帰路 定山渓 -> 札幌駅：

https://www.jotetsu.co.jp/bus/kappa_liner/index.html

  • 帰りは11:00にチェックアウトして温泉街を散策し、その後帰る予定だったので、13:15発（白髭の滝13:31乗車）の便を予約しました。

予約方法：

  1. 公式予約サイトで会員登録をする

  • Email / 台湾の携帯番号は問題ありません。

  • 必ずアカウントとパスワードを覚えておいてください。電子チケットはオンラインで直接有効化し、運転手に確認してもらいます。

2.購入する かっぱライナー号 / Kappa Liner 往復または片道

3.人数の選択

  1. 往路の日付と便を選択（便の時間は札幌発を基準としています）

  1. 行きの乗降場所を選択

乗降駅は以下の図表を参照してください：

https://www.jotetsu.co.jp/bus/kappa_liner/index.html

私たちのホテルは (2) 白糸の滝/Shiraitonotaki に近いため、こちらの駅で降りる予約をしました。

後で気づきましたが、ぐるっと一周して (7) Jozankei onsen higashi 2 chome / 定山渓温泉東2丁目 バス停で降りることもでき、そこがホテルの目の前です。

  1. 帰りの日付と便を選択（便の時間は出発駅基準）、乗降場所

6.オンラインカード決済の完了

価格：大人一人あたり¥2,920。

予約が成功するとメール通知が届き、チケット交換は不要で、チケットサイトでオンライン有効化し、そのまま運転手に見せるだけでOKです。

札幌 つなぐ 横町

駅の近くに夜市がまだ営業しているのを調べて、ぶらっと見に行きました。何でもいいので、何か食べようと思います。

適当に串焼き（主に鰻の串焼き）がある店を選んで、まず少し食べました。

こちらのお店も3月までの営業で、手羽先を食べたかったのに、間違えて別のお店を選んでしまいました。

22:30 ホテルに戻る

食べ終わってまだ少しお腹が空いていたので、近くのコンビニで夜食を買って帰りました。

Seicomart は Lawson や 711、ファミリーマートにない商品をいくつか販売しています。

Day 5 (03/19 木) — ショッピングと北海道神宮散策

10:00 朝食を食べに出発 マクドナルド

  • McGriddles ホットケーキバーガー（台湾では販売なし）— ベーコンチーズエッグ、ハチミツの甘じょっぱい味

  • ストロベリーチーズパイ（台湾でも後に販売開始）— ストロベリージャム＋チーズ

10:00 大通 狸小路でガチャガチャとドン・キホーテで買い物を続ける

札幌駅はあまり見るところがなく、こちらの方が色々と見て回れます。

火災報知器のガチャガチャといくつかの面白いガチャガチャ。

13:30 札幌駅のホテルに荷物を置き、百貨店で引き続き買い物と食事を楽しむ

昼食はデパートで散らし寿司とそばを適当に食べました。

LE LABO ル ラボ 札幌大丸店

ついでに Le Labo 2026 / 札幌での購入価格をチェック：

  • 50ml ¥31,350 と 2025年東京の価格と同じ

買い物をして、15:00頃に北海道神宮へ出発。

札幌から南北線に乗り、大通駅で東西線に乗り換え円山公園駅へ。所要時間は約30分です。

15:40 円山公園駅に到着

もし早めに行けるなら、近くの有名な北海道海産回転寿司 Toritonに先に行くのもおすすめです。

円山公園駅3番出口を出て、公園の方へまっすぐ進むと北海道神宮があります。

所要時間：約850メートル / 15分

道路を渡るとすぐに公園の入口です：

友達と円山で待ち合わせするとき…

私：円山公園 💁

まず円山公園を通り抜けます（ここにはまだ多くの積雪があります）、すると神宮の鳥居入口が見えます：

15:50 神宮茶屋

歩いて行くと神宮茶屋を通るので、まず北海道ミルクのアイスクリームを食べに行きます。

とても濃厚で美味しいです。

神宮内での飲食は禁止されています。茶屋で食事を済ませてから移動してください。

16:15 北海道神宮

参拝：五円玉を投げる（縁結びの意味）-> 二回お辞儀 -> 二回拍手 -> 願い事 -> 最後に一回お辞儀

お守りを二つ買いました。特に珍しいのは交通安全のお守りで、車内に掛けられるものと、バイク、自転車、ヘルメットに貼れるステッカーが付いています。

16:30 北海道神宮を出発

神宮と公園からゆっくり歩いて地下鉄駅へ戻り、札幌駅周辺で夕食を食べる準備をしました。

17:20 札幌北海道庁赤レンガ庁舎を通過

ただ通りかかっただけで、主に隣の札幌三井で焼肉を食べに行きました：

17:30 焼肉バル たむら 焼肉

北海道和牛を試してみましょう。

北海道牛セット＋サラダ＋ビール＋ドリンク＋冷麺を注文し、合計で約NT$3,100でした。和牛の脂が豊富で口の中でとろけ、ステーキも美味しかったですが、一番驚いたのは牛タンで、とても弾力があり美味しかったです。

19:00 札幌東急百貨店

お腹がいっぱいになった後、最後に東急百貨店へ行きました。

こちらの上の階にもおもちゃやガチャガチャがあります。

20:00 札幌駅に戻る

デパートはもうすぐ閉店なので、最後にもう一度見て回ります。

札幌駅 — サンドイッチ工房 Sandria

ホテルに戻る途中、毎日通るJR駅でいつも行列ができているサンドイッチの自動販売機で買いました。

一人につき2つまで購入可能で、私は夜食にとんかつを、翌朝の朝食にポテトと卵のサラダを買いました。

22:30 札幌最後の夜の夜食

初日にはイチゴ酒と北海道ミルクアイスクリームをいただきました。

Day 6 (03/20 金) — 新千歳空港、帰路

10:00 起床して部屋で朝食を食べる

食事を終えて片付けたら、チェックアウトしてそのまま空港へ向かいました。

11:05 札幌駅でバス待ち

11:19 札幌駅から新千歳空港へ出発

快速エアポート 68快速新千歳空港、38分

12:00 新千歳空港に到着

JR 新千歳空港、国内線ロビー

地下鉄で1階のロビーに上がると、多くの飲食店やお土産店があります。足りなければここでさらに買い物ができます。

帰る時間…来た道をそのまま戻る

12:17 国際線ロビーに到着

一番端のカウンターに割り当てられ、到着までに165メートル歩かなければなりません：

北海道のトリギンノドナガオヤマガラ：

12:22 チェックインカウンターに到着

現地は混雑しているため、オンラインチェックインは少なめです。必ず帰国の3日前までに座席指定とオンラインチェックインを済ませて、待ち時間を節約しましょう。

こちらの後ろにもう一軒ドン・キホーテがあり、荷物を預ける前の最後の買い物ができます：

13:03 チェックイン完了＋荷物預け入れ

13:17 セキュリティチェックと出国審査完了

日本の空港の保安検査は厳しく、ブーツを履いている場合は必ず脱いでX線検査を受ける必要があります。

13:20 搭乗待ちの間に散策

美食街があり、パン、唐揚げ、メロンアイスクリームを少しだけ買って食べました。

1階にはお土産店がずらりと並んでいて、ほとんど何でも買えますが、ブランドショップは少なめです。

2階にもいくつかお土産があります。

14:30 搭乗完了

来た時と同じく、新しいエアバス機で、座席が広く、エンターテインメント設備も新しいです。

15:00 出発、さようなら — 札幌

機内食は相変わらず普通でした：

18:15 台湾桃園国際空港に到着

19:15 入国＋荷物受取、帰宅して休息

今回の荷物がすごく長く待たされた…

ご覧いただきありがとうございます

ここまでご覧いただきありがとうございます。一緒に北海道のさまざまな景色を体験しましょう。次の場所でお会いしましょう！

機内無料WiFi

この便ではチャイナエアラインが全行程でメッセージ用WiFi機能を提供しており、友達とメッセージのやり取りができます。

スマホにAdGuard DNSや類似のDNS広告ブロックサービスをインストールしている場合は、設定 -> 一般 -> VPNとデバイス管理 -> 制限とプロキシサーバー -> DNS -> 自動に戻す必要があります。

そうしないと機内WiFiに接続できません。

戦利品

  • 札幌農学校（ミルククッキー）、焼きとうもろこしスナック（膨化食品）もおすすめです。

おもちゃ

  • 踏切、看板の灯り、車の鍵、火災報知器、ドン・キホーテのフィギュア、日本代表チームのユニフォーム

  • 富良野の精霊台で買った木製の手作り楽器
